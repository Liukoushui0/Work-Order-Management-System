### 3.2 越权与数据隔离

| 层次 | 实现 | 验证方式 |
| --- | --- | --- |
| 接口级 | `@PreAuthorize` + 权限编码（30 项权限，四角色 65 条授权） | 集成测试覆盖客户/工程师/客服/管理员边界 |
| 资源级 | `AccessGuard` 校验"操作人与工单/客户/设备的关系" | 跨客户访问 403/1102、非负责人操作 403/1405 |
| 数据域 | `DataScopeService` 为列表自动附加范围条件 | 客户列表仅 1 条、工程师列表仅本人、统计 `scope=SELF` |
| 附件 | 先校验工单访问权限，再校验路径规范化 | 他人工单附件 403/1102、附件与工单不匹配 404/1505 |
| 评价 | 仅所属客户的已完成工单且未评价 | 409/1501、409/1502、403/1102、403/1101 |

### 3.3 SQL 注入与输入校验

- 所有查询通过 MyBatis-Plus 参数占位（`#{}` / Lambda Wrapper），未发现字符串拼接用户输入。
- 6 个列表查询全部声明排序字段白名单，非白名单字段返回 `1202`（已有单元测试覆盖注入样式取值）。
- 字符串型 `LIMIT` 仅使用代码内常量，不来自请求参数。
- 请求参数统一使用 DTO + Bean Validation（含手机号、邮箱、编号格式、枚举取值、长度上限）。

### 3.4 文件访问安全

- 上传：扩展名白名单与大小上限取自 `sys_config`；原始文件名经清洗（去目录、去控制字符、限长）；存储名为 UUID，按 `ticket-{id}/{yyyy-MM}` 分目录；落库 SHA-256。
- 下载：先校验工单访问权限，再将相对路径与存储根目录规范化比对，越界即拒绝；响应为文件流，不暴露物理路径。
- 删除：逻辑删除 + 物理文件清理；员工仅能删除自己上传的附件。
- 存储目录 `backend/storage/attachments` 位于 Web 根之外，且已被 `.gitignore` 排除。

### 3.5 日志与错误信息

- 审计切面对 `password`、`token`、`secret`、`credential` 等字段做脱敏后再入库（集成测试断言失败登录的审计记录不含明文密码）。
- 业务异常只记录摘要（WARN），系统异常记录堆栈但对外统一返回 `1601`，不泄露内部实现。
- traceId 贯穿请求、日志与响应头，便于问题追踪。
- 未发现 `console.log`、`debugger`、`TODO/FIXME` 等调试残留。

### 3.6 认证与令牌

- BCrypt 存储密码；连续失败 5 次锁定 15 分钟（阈值与时长来自系统配置）。
- 无状态会话，退出登录与修改密码会将令牌 `jti` 写入 Redis 黑名单（TTL 为剩余有效期）。
- 每个请求重新加载用户角色与权限，权限变更与禁用立即生效（集成测试验证角色变更后权限即时生效）。
- **已知取舍**：前端将 access token 存于 localStorage，存在 XSS 场景下被读取的风险；本项目通过短有效期（2 小时）+ 后端强制鉴权控制影响面，如需更强保护可改为 HttpOnly Cookie + CSRF 令牌。

## 4. 越权、状态机、事务与并发复查

| 项 | 结论 |
| --- | --- |
| 状态机 | 转换矩阵集中在 `TicketStatus`，主流程与退回、转派、退回重做、重新打开、取消均有显式允许列表；终态不可再变更 |
| 非法跳转 | 由 `requireTransition` 拦截并返回 1402；集成测试覆盖待分派接单、待接单直接完成等场景 |
| 事务边界 | 事务在 Service 层，覆盖"更新工单 + 处理记录 + 分派记录"；文件 IO 与缓存操作不包裹在事务内 |
| 乐观锁 | 状态流转使用「状态 + 版本号」条件更新，影响 0 行时区分 1402/1403/1602 |
| 并发接单 | Redis 锁 10s + 条件更新双保险；4 线程并发测试仅 1 次成功，ACCEPT 记录恰好 1 条 |
| 并发建单 | 序列表 `INSERT ... ON DUPLICATE KEY UPDATE` 原子取号，5 线程并发编号互不重复 |
| 重复评价 | 唯一索引 `uk_evaluation_ticket` 兜底，返回 1502 |
| 自动确认 | 条件更新 + 版本号保证不重复确认；配置关闭时不查库直接返回 |
| 缓存一致性 | 写操作在事务提交后清理统计缓存（`afterCommit`），避免并发读回填旧数据 |
| 唯一性约束 | 工单编号、附件分派有效性、评价一单一评、设备编号与序列号、客户编号等均有数据库约束兜底 |
